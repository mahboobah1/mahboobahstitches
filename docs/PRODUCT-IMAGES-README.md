# Product photos

20 photos, background removed, resized to 1200 x 1500 (4:5, the shape the shop uses), saved as WebP with a transparent
background (about 50 to 250 KB each). They install to `public/images/products/` and are then live on your site at
`/images/products/<file-name>.webp`.

`product-images-manifest.csv` lists, for every file, a suggested product name, collection and alt text (a short
description for screen readers and Google). These are suggestions from what is visible in the photos. Fabric, sizes,
prices and care details are not guessed: you add those in Admin > Products.

Two files are the same product from two angles:
`two-piece-navy-khimar-gold-button-1.webp` and `two-piece-navy-khimar-gold-button-2.webp`.

Colours were left true to the originals (only gentle brightness, noise and sharpness clean-up). The cutouts were made
automatically, so check the edges when you add each photo. Re-send any that look rough and I will fix them.
